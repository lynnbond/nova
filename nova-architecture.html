Nova Engine — Architecture

Go嵌入式工作流引擎 · 771 节点 · 2492 边 · Go + TypeScript

Engine Core

  • • State machine: DRAFT → SUBMIT → BACK → OVER
  • • 7 activity types: START, MANUAL, ROUTER, CONVERGE, WAIT, TAIL, END
  • • 3 handler policies: SINGLE, EXCLUSIVE, CONCURRENT
  • • DecisionFilter 路由选择 / ForceOpinion 强制意见
  • • HookRouter 扩展点 (BEF_SUBMIT, BEF_CHOOSE_*)

HTTP API Layer

  • • JWT 认证 + 用户模块 (CRUD)
  • • 实体 CRUD：创建、提交、退回、获取详情
  • • 流程设计：load / save / publish / delete
  • • 待办/已办：todos → outbox
  • • 意见系统：获取/添加意见 + 处理日志

Persistence

  • • Store 接口：15 方法定义
  • • SQLite 实现：~1350 行、WAL 模式
  • • 表结构：process / pro_ver / act / act_link / man_rule
  • • 运行时表：entity / run_task / run_todo / run_step
  • • 日志表：handle_log / step_log / opinion
